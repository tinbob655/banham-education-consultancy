# Banham Education Consultancy — Website

A React-based website for **Banham Education Consultancy**, providing expert support for trusts, schools, and students through effective teaching and learning strategies.

🌐 **Live site:** [banhameducationconsultancy.com](https://www.banhameducationconsultancy.com)

---

## About

Banham Education Consultancy offers professional educational services aimed at improving results and engaging all learners. Services span support for:

- **Multi-academy trusts & schools** — strategic and operational educational support
- **Students** — tutoring and tailored learning strategies
- **Training** — professional development for educators

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-org/banham-education-consultancy.git
cd banham-education-consultancy

# 2. Install dependencies
npm install

# 3. Start the development server
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000).

---

## Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Runs the app in development mode with hot reloading |
| `npm run build` | Builds the app for production into the `/build` folder |
| `npm test` | Launches the test runner in interactive watch mode |
| `npm run eject` | Ejects from Create React App (one-way operation — use with caution) |
